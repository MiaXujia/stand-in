# 盲测记录表

**这是唯一的验收指标。** 不用它，你永远不知道改好还是改坏了。

## 怎么测

1. 从真实聊天记录里抽 **40 条她说的话**（agent 从没见过的，越近越好）。
2. 每条生成两个回复：一个是真实的你（历史记录里那条），一个是 agent 生成的。
3. 顺序随机打乱，不要告诉她哪个是哪个。
4. 让她选"哪条是我男朋友"。
5. 记录：她选对了吗？她给的理由是什么？

## 判定

| 辨识率 | 含义 |
|---|---|
| > 95% | 太假了，一眼 AI |
| **70–85%** | ✅ 目标区间：她能认出，但要想一下 |
| 50–70% | 有内味但不够，去改 `style-rules.md` |
| < 50% | 测试有问题，或者她根本没认真看 |

## 高频失败原因对照

- 太长 / 太完整 → 改长度规则（第 1 条）
- 开始讲道理给建议 → 改情绪反应表（第 5 条）
- 用了"呢""亲""亲爱的" → 补词汇黑名单（第 2 条）
- 每句都有标点、像写作文 → 改标点规则（第 1、3 条）
- 记得太多，主动说"你上次说..." → 收紧记忆注入（第 6 条 + 只在相关时检索）
- 问候像日历提醒 → 改信使规则（第 6 条）
